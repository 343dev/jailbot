# 02 — Сделать help и version безопасными discovery-командами

**What to build:** пользователь может узнать назначение, синтаксис и версию Jailbot в неподготовленном окружении, не запуская Docker и не получая терминальные управляющие байты в выводе.

**Blocked by:** 01 — Создать строгий process-level контур тестирования CLI.

**Status:** done

- [x] `-h` и `--help` без `JAILBOT_IMAGE_NAME` и `SSH_AUTH_SOCK` выводят справку в `stdout`, оставляют `stderr` пустым и завершаются с кодом `0`.
- [x] Help имеет приоритет над несвязанными wrapper-ошибками во всех аргументах до `--`, но `--help` после separator передаётся контейнерной команде.
- [x] `--version` не зависит от Docker или конфигурации, выводит одну стабильную строку в `stdout` и завершается с кодом `0`.
- [x] Discovery-команды не вызывают Docker и не выполняют другие внешние эффекты.
- [x] В перенаправленном или piped `stdout`, а также при `TERM=dumb`, отсутствуют ANSI и другие terminal control bytes.
- [x] Справка ведёт с краткого описания и типовых примеров, показывает `-h, --help`, объясняет separator и bare invocation, а также содержит ссылки на документацию и issue reporting.
- [x] README синхронизирован с опубликованными help/version-синтаксисом и поведением.
