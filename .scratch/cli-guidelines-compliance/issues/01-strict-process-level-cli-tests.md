# 01 — Создать строгий process-level контур тестирования CLI

**What to build:** надёжный тестовый контур, который проверяет Jailbot как отдельный процесс и точно фиксирует публичный CLI-контракт, чтобы последующие исправления нельзя было ошибочно признать рабочими по расплывчатому совпадению вывода.

**Blocked by:** None — can start immediately.

**Status:** done

- [x] Тесты раздельно фиксируют и сравнивают `stdout`, `stderr` и точный exit status для успешных и ошибочных вызовов.
- [x] Docker stub записывает каждый элемент `docker run` argv без потери пустых значений, пробелов или специальных символов и позволяет сравнить полную последовательность аргументов.
- [x] Тесты могут доказать, что Docker не вызывался после ошибки разбора или валидации.
- [x] Проверки не отмечаются успешными без фактического assertion; существующие ложноположительные ветки устранены.
- [x] Базовая матрица покрывает help, separator, неизвестные опции, перенаправленные потоки и обычный запуск контейнерной команды.
- [x] Тестовый контур остаётся переносимым в рамках поддерживаемого проектом POSIX shell окружения.

## Comments

Реализован единый process-level harness с файловым argv-кодированием, строгими assertions потоков/status и учётом вызовов Docker. Проверено `sh -n`, `shellcheck` и полным запуском тестового файла.
