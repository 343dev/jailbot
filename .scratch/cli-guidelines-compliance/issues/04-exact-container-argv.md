# 04 — Передавать контейнерной команде точный argv

**What to build:** Jailbot действует как прозрачный wrapper и передаёт Docker ровно ту контейнерную команду, которую указал пользователь после separator, без потери, перестановки или добавления аргументов.

**Blocked by:** 01 — Создать строгий process-level контур тестирования CLI.

**Status:** done

- [x] Сохраняются количество, порядок и точное содержимое аргументов, включая пустые строки, пробелы, wildcard-символы и обратные слеши.
- [x] После Docker image не добавляется отдельный служебный `--`; обычные образы получают стандартный контракт `IMAGE COMMAND...`.
- [x] Bare invocation по-прежнему запускает default command или entrypoint образа без искусственной контейнерной команды.
- [x] Значения, которые выбранное POSIX-представление не может безопасно сохранить, отклоняются явно с ненулевым статусом вместо молчаливой потери или изменения.
- [x] Process-level тесты сравнивают полную последовательность Docker argv, включая позиции пустых аргументов.
- [x] Документация точно описывает separator и границу между wrapper-options и контейнерной командой.

## Comments

Container argv переведён с newline-delimited строки на временное файловое представление с одним файлом на аргумент. Это сохраняет пустые значения и специальные символы; literal newline отклоняется до Docker. Нестандартный `--` после image удалён.
